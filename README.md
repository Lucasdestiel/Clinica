🏥 Clínica Vida +

Um site institucional moderno e responsivo desenvolvido para apresentar a Clínica Vida +, destacando seus serviços, depoimentos de clientes e canais de contato de forma clara e profissional.

✨ Sobre o Projeto

Este projeto foi criado com o objetivo de oferecer uma presença digital elegante e funcional para a clínica, proporcionando uma navegação simples e agradável para os visitantes.

O site conta com:

✅ Apresentação da clínica
✅ Layout moderno e responsivo
✅ Seção de depoimentos
✅ Formulário de contato via e-mail
✅ Botão flutuante de WhatsApp
✅ Navegação intuitiva
✅ Design focado na experiência do usuário

🎯 Objetivo do Projeto

O principal foco foi desenvolver uma landing page institucional que transmitisse:

Profissionalismo
Credibilidade
Facilidade de contato
Boa experiência para o usuário
📱 Funcionalidades
📨 Contato por E-mail

Ao final da página, o usuário encontra um formulário simples e objetivo para envio de mensagens.

💬 Botão Flutuante do WhatsApp

Um botão fixo na tela permite contato rápido e direto com a clínica via WhatsApp.

⭐ Depoimentos

Área dedicada a feedbacks de clientes para aumentar a confiança e credibilidade da clínica.
